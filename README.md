# EB360 Final Prep

เว็บติวไฟนอลวิชา EB360 บทที่ 5–9 (เว็บหน้าเดียว ไม่ต้อง build)

## ในเว็บมีอะไร
- **วิธีทำข้อสอบ** รูปแบบข้อสอบ สูตรทำคะแนน และนับถอยหลังถึงวันสอบ
- **สรุปบท** เนื้อหาเต็มจากชีทสรุป Ch 5–9 พร้อมคำอธิบายเพิ่มให้เข้าใจง่าย
- **ศัพท์** 39 คำ มีนิยาม ตัวอย่าง คำแปลไทย และโหมดซ่อนนิยามไว้ทดสอบตัวเอง
- **Essay** 16 ข้อที่น่าจะออก พร้อมโครงคำตอบและคำตอบตัวอย่าง
- **เชื่อมข้ามบท** ประเด็นที่โยงหลายบทเข้าด้วยกัน
- **จำลองสอบ** สุ่มข้อสอบพร้อมตัวจับเวลา

## เปิดใช้บน GitHub Pages
1. สร้าง repository ใหม่บน GitHub (ต้องเป็น Public ถ้าใช้บัญชีฟรี)
2. อัปโหลด `index.html`, `README.md` และ `.nojekyll` ขึ้นไปที่ branch `main`
3. ไปที่ **Settings → Pages**
4. ตรง **Source** เลือก **Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` จากนั้นกด **Save**
5. รอ 1–2 นาที เว็บจะขึ้นที่ `https://<username>.github.io/<repo-name>/`

## หรือใช้คำสั่ง git
```bash
git init
git add .
git commit -m "EB360 final prep site"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```
จากนั้นเปิด GitHub Pages ตามข้อ 3–4 ด้านบน

## หมายเหตุ
- ข้อมูลที่ติ๊กว่า "จำได้แล้ว" เก็บไว้ในเบราว์เซอร์ของแต่ละคน ไม่ได้ส่งไปที่ไหน
- คำถาม Essay เป็นการคาดการณ์จากชีทสรุป ไม่ใช่ข้อสอบจริง
